## Что такое AD
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Служба каталогов — метод иерархического представления объектов в рамках сетевой операционной системы.  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Служба *Active Directory* разработана и поддерживается компанией Microsoft. В настоящий момент она является инструментом для интеграции других служб операционной системы Windows Server.   
  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; При помощи Active Directory администраторы сети могут распространять групповые политики, обеспечивая единые настройки среды работы для множества пользователей. Служба также используется для централизованной установки и обновления программного обеспечения на компьютерах сети.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Технически, мы храним здесь информацию о пользователях, компьютерах, группах, политиках безопасности и конфигурации домена, все это хранится в NTDS.dit (на контроллере домена).  

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *NTDS.dit* — это основной файл базы данных Active Directory в Windows Server. Кроме перечисленного выше он хранит хэши паролей и обеспечивает аутентификацию в сети. Файл находится по пути %SystemRoot%\NTDS, а обслуживается через утилиту ntdsutil (например, для дефрагментации или проверки целостности). Технологически он представлен как БД на Jet Blue, состоящей из двух таблиц, которые, в свою очередь, разделены на разделы (Domain (Данные домена), Configuration (Топология сети), Schema):  
- *Data Table:* Хранит все объекты AD
- *Link Table:* Хранит связи между объектами

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Для аутентификации используются основные протоколы: Kerberos, NTLM. Управление осуществляется через следующие порты:
- DNS: TCP/UDP **53** — поиск контроллеров домена
- Kerberos: TCP **88** — аутентификация пользователей и устройств
- NTP: TCP/UDP **123** — синхронизация времени для Kerberos
- RPC: TCP/UDP **135** — управление и репликация данных
- LDAP: TCP **389** — запросы к каталогу AD
- SMB: TCP **445** — доступ к файлам, репликация SYSVOL
- LDAPS: TCP **636** — защищенные запросы к каталогу
- Global Catalog: TCP **3268/3269** — поиск объектов в лесу AD
- Динамические RPC: TCP/UDP **49152–65535** — репликация и управление
