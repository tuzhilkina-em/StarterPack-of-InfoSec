## Какие права по умолчанию есть у пользователя на просмотр объектов AD?

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; В Active Directory модель прав построена так, что любой аутентифицированный пользователь по умолчанию может читать каталог. Это реализовано через группу *Authenticated Users*, которой на уровне домена и контейнеров выданы разрешения на чтение. Пользователь может выполнять LDAP-запросы и получать информацию об объектах: пользователи, группы, компьютеры, OU. Он может видеть такие атрибуты, как имя, sAMAccountName, членство в группах, описание и другие поля, которые защищены не были. Например, те же пароли не хранятся и не читаются в явном виде, а некоторые объекты защищены отдельно, например, c помощью acl

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Кроме того, существуют механизмы вроде Confidential Attributes, где доступ к конкретным атрибутам нужно явно разрешать. На уровне прав это выглядит как набор разрешений: Read, List Contents, Read All Properties. Они позволяют просматривать структуру каталога и свойства объектов, но не дают возможности изменять их. Изменение (Write), удаление (Delete), сброс пароля и другие операции требуют отдельных прав. Существует режим анонимного доступа, который по умолчанию является выключенным, поэтому в основе без авторизации пользователь не увидит каталог вообще
