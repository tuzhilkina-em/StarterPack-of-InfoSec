## Как работает механизм Protected Users
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ***Protected Users*** - это специальная группа Active Directory, предназначенная для защиты привилегированных учетных записей от кражи учетных данных и legacy-аутентификации. Когда пользователь входит в эту группу, DC и LSASS начинают применять к его сессии дополнительные ограничения. Для такого пользователя запрещается NTLM-аутентификация, отключается использование DES и RC4 в Kerberos, запрещается delegation, а Kerberos TGT получает сокращенное время жизни. Windows также перестает кэшировать некоторые типы учетных данных в памяти LSASS, из-за чего усложняются Pass-the-Hash и credential dumping атаки  

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Механизм начинает работать через KDC и LSASS во время аутентификации. Контроллер домена проверяет membership пользователя в группе Protected Users, и изменяет поведение Kerberos и authentication policy для этой учетной записи. Минимальные требования функционирования - Windows Server 2012 R2, как минимум для DC, потому что именно начиная с этой версии KDC умеет применять ограничения Protected Users.
