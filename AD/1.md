## Что такое AD
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Служба каталогов — метод иерархического представления объектов в рамках сетевой операционной системы.  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Служба *Active Directory* разработана и поддерживается компанией Microsoft. В настоящий момент она является инструментом для интеграции других служб операционной системы Windows Server.   
  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; При помощи Active Directory администраторы сети могут распространять групповые политики, обеспечивая единые настройки среды работы для множества пользователей. Служба также используется для централизованной установки и обновления программного обеспечения на компьютерах сети.
