## Как принудительно запустить репликацию каталогов на контроллере домена
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Для контроля хода репликации объектов AD можно использовать средства PowerShell из модуля Active Directory
Для диагностирования проблем с репликацией AD и принудительного вызова омераций также полезны утилиты dcdiag​​, repadmin, nslookup

### Repadmin
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *Repadmin* - это инструмент командной строки в Windows Server для диагностики, мониторинга и управления репликацией Active Directory (AD). Он позволяет администраторам проверять состояние репликации между контроллерами домена, выявлять сбои, просматривать метаданные и вручную запускать синхронизацию. Repadmin встроен в Windows Server (при установленной роли AD DS) и доступен на клиентских ОС через компоненты RSAT (Remote Server Administration Tools)  

repadmin 
- /syncall /AeD - немедленная принудительная сихронизация со всеми назначенными партнерами
- /showrepl - отображение статуса входящей репликации для каждого контроллера
- /kcc - принуждает службу Knowledge Consistency Checker (KCC) пересчитать топологию подключений
- /showobjmeta - вывод подробной информации о времени и источнике изменения конкретного объекта AD
- /queue - вывод списка задач, ожидающих репликации
