## 8. Kubernetes и Docker: зачем они используются и в чем их отличия?
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *Docker* – технология среды выполнения контейнеров, позволяющая создавать, тестировать и развертывать приложения быстрее, чем с помощью традиционных методов. Она упаковывает ПО в стандартизованные *контейнеры*, которые включают все необходимое для его работы. Docker работает на уровне хоста, позволяет упаковать приложение вместе со средой исполнения, но обеспечивает меньший уровень изоляции по сравнению с VM. 
<br>  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *Kubernetes* – это ПО для автоматизации развертывания, масштабирования и управления контейнеризированными приложениями. Он оркеструет контейнеры (например, Docker) на множестве серверов, обеспечивая отказоустойчивость, балансировку нагрузки и эффективное использование ресурсов.
<br>  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Docker и Kubernetes – это две разные технологии, и варианты их использования отличаются. Docker используется для запуска, редактирования и управления разработкой контейнеров, Kubernetes же - для масштабного запуска приложений производственного уровня.
