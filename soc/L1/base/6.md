## Kerberos
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *Kerberos* — это протокол сетевой аутентификации, использующий билеты (tickets) для подтверждения личности пользователя или службы без передачи паролей по сети. В Active Directory он обеспечивает безопасный единый вход (SSO), где Центр распределения ключей (KDC) на контроллере домена выдает билеты, позволяющие пользователю получать доступ к ресурсам, подтверждая права  

![Логика работы](https://github.com/tuzhilkina-em/StarterPack-of-InfoSec/blob/1b1223c30bfd691f1062143ed423c2f5c9cf75c9/soc/L1/base/images/6.jpeg)

Логика работы протокола:
1. Запрос (AS-REQ): Пользователь вводит логин/пароль. Клиент отправляет запрос к KDC (Authentication Service)
2. Выдача TGT (AS-REP): KDC проверяет данные и выдает TGT (Ticket Granting Ticket) — билет на получение билетов
3. Запрос билета службы (TGS-REQ): Пользователь хочет получить доступ к ресурсу (например, файловому серверу) и отправляет TGT в KDC (Ticket Granting Service)
4. Выдача TGS (TGS-REP): KDC проверяет TGT и выдает билет службы (Service Ticket/TGS) для конкретного ресурса
5. Доступ к ресурсу (AP-REQ/REP): Пользователь отправляет TGS на сервер ресурсов, который проверяет его и предоставляет доступ
