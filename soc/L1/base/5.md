## 5. Что такое Mimikatz и где он используется?
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Mimikatz - это утилита, предназначенная для извлечения учетных данных (паролей, хэшей, токенов аутентификации) из операционной системы Microsoft Windows.  
Основные направления использования:  
  - Извлечение паролей в открытом виде, если они присутствуют в памяти процессора;
  - Получение NTLM-хэшей паролей;
  - Извлечения Kerberos-билетов;
  - Проведение атак типа Pass-the-Hash и Pass-the-Ticket.
<br>

### Работа Mimikatz с технологической точки зрения
  -  **Работа LSASS (Local Security Authority Subsystem Service).** Цель - получение доступа к памяти процессора, и, как следствие, к хранимым данным. Это достигается следующим образом:
        1. Повышение привилегий (SeDebugPrivilege)
        2. Работа с процессорами LSASS(OpenProcess)
        3. Чтение(ReadProcessMemory)
     
  -  **Извлечение учетных данных (Credential Providers).** Mimikatz реализует парсеры для разных пакетов аутентификации Windows.
  -  **Cигнатурный поиск в памяти**
<br>
  
### Атаки Pass-the-Hash
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Для реализации атаки хеши пароля от целевой учетной записи извлекаются, а затем используются для аутентификации от имени этого пользователя. После аутентификации метод передачи хеша может использоваться для выполнения действий в локальных или удаленных системах.  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Злоумышленники также могут использовать украденные хеши паролей для реализации техники Overpass the Hash. Она предусматривает использование хеша пароля для аутентификации от имени пользователя, аналогично методу передачи хеша, а также для создания действительного билета Kerberos. Этот билет впоследствии может использоваться для проведения атак типа Передача билета (Pass the Ticket).

<br>
  
### Атаки Pass-the-Ticket
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Для реализации этой техники действительные билеты Kerberos для существующих учетных записей извлекаются путем получения дампа учетных данных.  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Серебряный билет Kerberos предоставляет доступ к службам, которые используют Kerberos в качестве механизма аутентификации и генерируют билеты для доступа к конкретному ресурсу и системе, в которой он размещен. Золотой билет Kerberos генерируется с помощью NTLM-хеша доменной учетной записи службы распространения ключей KRBTGT и позволяет генерировать TGT для любой учетной записи в Active Directory.
