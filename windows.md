## Вопросы Windows

1. **Как сделать скриншот (части) экрана?**    
  - Win+Shift+S - открыть инструмент «Ножницы», выделить нужную область, скриншот копируется в буфер
  - Win+PrtSc - сохранить полный экран в «Изображения - Screenshots»
  - PrtSc - скопировать весь экран в буфер обмена
  - Alt+PrtSc - скриншот активного окна в буфер
  - В Microsoft OneNote: Win+Shift+S (или встроенный «Вырезка экрана») - вставка сразу в заметку  
<br>  
  
2. **Как просто проверить, что заданный удаленный компьютер с ОС Windows?**    
  - Проверить порт 3389 (RDP) - открыт почти всегда только на Windows (mstsc)
  - Подключиться к SMB (порт 445) - Windows-расшаренные ресурсы (\\host\C$)
  - TTL в ответе ping ~ 128   
  - Запросить NetBIOS-имя (nbtstat -A IP) - характерно для Windows-сетей
  - Сканирование через Nmap с -O - определяет ОС по сигнатурам сети   
<br>


3. **Как посмотреть события Windows на локальном и удаленном компьютере?**
  - Локально: Win+R - eventvwr.msc - открыть Event Viewer
  - Локально: (CLI): wevtutil qe System / Get-EventLog / Get-WinEvent в PowerShell
  - Удалённо: (GUI): в Event Viewer - «Подключиться к другому компьютеру»
  - Удалённо: (PowerShell): Get-WinEvent -ComputerName HOST (нужны права и доступ)
  - Через WMI/WinRM: wevtutil /r:HOST или PowerShell Remoting (Enter-PSSession HOST)  
    Для удаленного доступа нужна админка и доступ по сети
<br>  


4. **В каком журнале находятся события об авторизации? Какие нужны права для их просмотра?**  
Во-первых, в исходном виде нужные eventid:
- 4624 - успешный вход
- 4625 - неуспешный вход
- 4634/4647 - выход из системы
- 4672 - вход с привилегиями администратора
- 4768/ 4769/4771 - kerberos, доменные события  
Они лежат в журнале security в event viewer, по умолчанию доступ только у админа  
<br>  


5. **Как узнать IP адрес и имя компьютера? Как узнать имя заблокированного (Win-L) компьютера?**  
Если говорить о стандартных способах:  
- ipconfig - показывает IP-адреса интерфейсов
- hostname - имя компьютера
- ipconfig /all - сразу и IP, и имя (HostName)
- В PowerShell: Get-ComputerName или $env:COMPUTERNAME  

Если компьютер заблочен, на экране блокировки имя обычно видно под полем входа. Либо же формат DOMAIN\username / COMPUTERNAME\username - по нему видно имя ПК. Еще вариант: ping -a IP или nbtstat -A IP - резолвит имя удалённой машины  
<br>

7. **Как проверить, какие пользователи могут подключаться удаленно к серверу?**  
Доступ к rdp дается либо через локальную группу, либо через политики - оба варианта надо проверять  
Я бы смотрела так:  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 1) net localgroup "Remote Desktop Users" - локально  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 2) gpresult /h report.html - какие GPO применились  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 3) В GPO - Allow log on through Remote Desktop Services  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 4) Членство доменных групп в AD
<br>


9. **Как посмотреть групповые политики, примененные к компьютеру?**  
  - gpresult /r - через консоль
  - gpresult /h report.html -закинуть отчет в HTML
  - gpresult /s HOST /r - посмотреть политики на удалённой машине
  - В Event Viewer - журнал GroupPolicy   
 <br>


9. **В каком порядке групповые политики применяются к компьютеру (доменные, локальные)?**  
Порядок LSDOU для групповых политик выглядит так:
- Local - сначала локальные политики на самом компьютере
- Site - затем политики сайта (если используется AD Sites)
- Domain - потом доменные
- OU -в конце политики организационных единиц  

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Если один и тот же параметр задан в нескольких местах - приоритет отдается тому, что применился последним (то есть ближе к объекту, обычно OU). Кроме того, можно принудительно задать приоритет через Enforced, блокировать наследование через Block Inheritance, а также настроить фильтрацию (Security/WMI)    
<br>   


10. **Где в Windows задаются параметры прокси сервера?**  
  - Через настройки системы: Settings-Network&Internet-Proxy
  - Через классическую панель: Internet Options (inetcpl.cpl)-Connections-LAN Settings
  - Через реестр (HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings)
  - Через групповые политики (GPO)
  - Через командную строку: netsh winhttp set proxy (для WinHTTP)  

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; В целом есть два уровня -пользовательские настройки (WinINet) и системные (WinHTTP), при чем они независимы - прокси, заданный в настройках пользователя (WinINet), не применяется автоматически к системным сервисам (WinHTTP), и наоборот  
<br>   


11. **Как сделать так, чтобы скрипт запускался при каждом входе пользователя или в заданное время?**  
  - Через планировщик задач - задать триггер «при входе» или по времени и указать скрипт
  - Через schtasks в командной строке - то же самое, но из CLI
  - Через папку автозагрузки (shell:startup) - скрипт запускается при логине пользователя
  - Через локальные групповые политики - задать logon-скрипт или задачу  
<br>   


12. **Как запустить процесс от имени другого пользователя?**  
  - runas /user:DOMAIN\user cmd - запуск процесса от другого пользователя
  В PowerShell:
  - Start-Process cmd -Credential (Get-Credential)
  - Через планировщик задач (taskschd.msc) - задать пользователя и запустить задачу
  Через PsExec:
  - psexec -u user -p password cmd
